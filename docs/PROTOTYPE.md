## Открытая версия (без сервера)

Опубликована на claude.ai (https://claude.ai/artifact/XtiPR52pXhL1sAGhmHnofK) и подготовлена для раздела «Приложения»
harekrishna.info (`/apps/dialogue-cards/`). Библиотека, просмотр, подборка со ссылкой и QR, выбор карты участником.
Состав подборки — в ссылке, выбор — в браузере участника; общей статистики нет. Сборка: `npm run build-static`.

## Где хранятся данные

| Данные | Где | Видно с других устройств |
|---|---|---|
| Карты, подборки, выборы, статистика | База SQLite на сервере | Да |
| Какую карту выбрал участник, номер раунда | Сервер + случайный идентификатор браузера в `localStorage` | Да, но участник «узнаётся» только в том же браузере |
| Язык интерфейса, сортировка в управлении | `localStorage` браузера | Нет (личные удобства) |

Если участник очистит данные браузера или откроет ссылку на другом телефоне, его прежний выбор не подтянется. Сам выбор в статистике при этом сохранится.

## Временные решения (предложения, требуют подтверждения)

1. **Ссылка показывает текущий состав подборки.** Изменения фасилитатора сразу видны по старой ссылке и QR. Отдельных копий для каждой встречи нет. Кнопки отключения ссылки нет.
2. **Правила выбора:**
   - в одном раунде у участника одна активная карта; выбор другой карты заменяет прежнюю;
   - повторное нажатие на ту же карту счётчик не увеличивает;
   - выбор можно отменить;
   - кнопка «Следующий раунд» позволяет выбрать новую карту, выбор прежнего раунда сохраняется и учитывается.
3. **Счётчик «Выбрали для обсуждения N раз»:**
   - в подборке участник видит его только после своего выбора;
   - в библиотеке счётчик спрятан в сведениях о карте (ⓘ);
   - в тестовых подборках счётчик не показывается.
4. **Учёт выборов.** В статистику идут только текущие выборы, отменённые и заменённые не считаются. Но они не удаляются из базы, а помечаются, так что историю можно пересчитать по другим правилам.
5. **«Предложена»** — сколько участников (браузеров) открыли подборку, где была карта. Нужно, чтобы сравнивать карты с разным числом возможностей быть выбранными.
6. **Тестовые подборки.** Выборы в подборке с пометкой «тестовая» хранятся отдельно и не смешиваются с реальной статистикой. Никаких выдуманных демо-выборов в базе нет.
7. **Снятие карты.** Карта пропадает из библиотеки и подборок, её изображения перестают открываться по прямой ссылке. Владелец подборки видит предупреждение «Недоступные карты». Карту можно вернуть.
8. **Коды карт** `DC-0001`… присваиваются автоматически по порядку. Первые 40 соответствуют номерам файлов печатной колоды (`1.pdf` → `DC-0001`).
9. **Автор карт первой колоды — Ананда Майя** (записан в `seed/cards/manifest.json`, проставляется при запуске там, где автор не указан).
10. **Визуальное направление:** тёплый светлый фон, золото из логотипа, тёмный фон для просмотра карт, заголовки шрифтом Cormorant Garamond (лицензия OFL, файлы шрифта лежат на нашем сервере). Это предложение, а не утверждённый дизайн.
11. **Логотип** — присланные файлы без перерисовки (`assets/brand/`): чёрный с прозрачным фоном — шапка, экран QR, значки; белый — тёмный блок Dialogue Flow; золотой — крупно на главной. Обрезаны только пустые поля.
12. **Карты для экрана** сделаны из PDF для печати: CMYK → RGB, поля под обрез (3 мм) срезаны по решению владельца — на экране видна карта 70×120 мм, как после резки. Высота 1600 px.

## Ограничения прототипа

- Вход владельца — один общий пароль. Регистрации по email, ролей художника, куратора и фасилитатора пока нет.
- Без регистрации нельзя точно посчитать уникальных людей: один человек с двух устройств считается дважды.
- Защита от накрутки минимальная: случайный идентификатор браузера, без ограничения частоты запросов.
- Порядок карт внутри подборки — порядок добавления, менять его пока нельзя.
- Исходные PDF (970 МБ) в репозиторий не добавлены, в нём только веб-версии.
