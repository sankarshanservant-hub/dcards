# Dialogue Cards

Веб-приложение для библиотеки иллюстраций Dialogue Cards и подборок карт для встреч Dialogue Flow.
Открывается по обычной ссылке и QR-коду в браузере телефона, без установки и регистрации участников.

Состояние прототипа, принятые временные решения и открытые вопросы: [docs/PROTOTYPE.md](docs/PROTOTYPE.md).

## Что внутри

| Путь | Что это |
|---|---|
| `server/` | Сервер на Node.js (Express) и база SQLite: карты, подборки, выборы, вход владельца |
| `public/` | Сайт: HTML, CSS, JavaScript без сборки, шрифт, логотип |
| `seed/cards/` | Веб-версии 40 карт первой колоды и рубашки (из PDF для печати) |
| `scripts/import-cards.js` | Перевод PDF/изображений карт в веб-версии |
| `test/` | Автоматические проверки (`npm test`) |
| `data/` | Создаётся при запуске: база данных и изображения. **Не в git, нужна резервная копия** |

## Запуск на своём компьютере

Нужен Node.js 20 или новее.

```bash
npm install
```

```bash
ADMIN_PASSWORD=придумайте-пароль npm start
```

Сайт откроется на http://localhost:3000. При первом запуске в библиотеку автоматически загружаются 40 карт из `seed/cards`.
Раздел управления — http://localhost:3000/admin (без `ADMIN_PASSWORD` в режиме разработки пароль `dcards-dev`).

Проверки:

```bash
npm test
```

## Настройки сервера

| Переменная | Назначение |
|---|---|
| `ADMIN_PASSWORD` | Пароль владельца проекта. В продакшене обязателен, без него вход закрыт |
| `PUBLIC_URL` | Публичный адрес сайта для ссылок и QR, например `https://example.org` |
| `DATA_DIR` | Папка для базы и изображений (по умолчанию `./data`) |
| `PORT` | Порт (по умолчанию 3000) |
| `SESSION_SECRET` | Ключ подписи сессии (если не задан, создаётся в `DATA_DIR`) |

## Размещение в интернете

Самый простой вариант — небольшой арендованный сервер (VPS) с Docker:

```bash
docker build -t dialogue-cards .
```

```bash
docker run -d --name dcards -p 3000:3000 -v dcards-data:/data -e ADMIN_PASSWORD=... -e PUBLIC_URL=https://ваш-домен dialogue-cards
```

Перед сервером нужен HTTPS (например, Caddy или nginx с Let's Encrypt). Том `/data` — это вся база и все изображения: его нужно регулярно копировать.

## Новые карты из PDF

```bash
node scripts/import-cards.js "папка/с/PDF" --out seed/cards
```

Нужен `pdftoppm` (пакет poppler-utils). Иллюстрация не обрезается и не ретушируется, только переводится в RGB WebP.
Через сайт карты добавляются в разделе «Управление → Карты и статистика» (JPG, PNG, WebP, TIFF).
